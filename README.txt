LIAD Space Defender V7.4 — Cosmic Skins Update

• Fixed LIAD skin switching: Neon Blue / Solar Gold / Void Violet.
• Skin choice is saved locally.
• Every one of the 10 levels now has its own procedural space palette/sector.
• Sector transition is visible on every level; after bosses the visual change is especially pronounced.
• Added EXIT button to the main menu. iOS/iPadOS does not permit a web app to force-close itself,
  so EXIT stops the game and shows a closed-session screen; swipe the app away to close it fully.
• Smart Hangar logic from V7.3 retained.
• Universal iPad + iPhone PWA retained.
